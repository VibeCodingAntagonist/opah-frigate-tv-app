# Opah 0.7.1

Opah 0.7.1 restores realtime activity updates after upgrading to Frigate 0.18.2.

- Frigate TV alerts and automatic Monitor activity updates can use compatible
  Frigate 0.18 builds without waiting for each exact build name to be listed.
- Camera activity refreshes correctly when Opah connects or reconnects.
- Compatibility information now includes Frigate 0.18.2 (`cfa08c5`). Other
  compatible 0.18 builds can connect, but are not all individually tested.

Camera permissions, PIN protection, guest mode, and notification privacy choices
continue to apply. Frigate 0.17.2 retains its existing camera-access safeguards.

See the [compatibility guide](../compatibility.md) for tested versions and
features.
