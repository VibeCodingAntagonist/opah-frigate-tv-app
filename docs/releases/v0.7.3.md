# Opah 0.7.3

Opah 0.7.3 gives cameras another way to connect when their usual live stream
cannot start.

- Hold **OK** on a camera and choose **Play using another connection**. This
  now also supports an existing no-login Frigate connection on a trusted
  private network, as well as supported secure connections.
- In **Settings** > **Cameras and Playback**, enable **Try another connection
  automatically** if you want Opah to try the same stream another way when
  required video setup details are missing. It starts off and resets when you
  change the saved server connection.
- Changing connections keeps the selected stream. Automatic quality no longer
  favors a stream simply because its label is Main when opening the other
  connection. Your deliberate Best quality or Low bandwidth choice still applies.

The other connection requires Frigate 0.18.2 or a compatible later stable 0.18
release. It uses the server you have already configured. PIN and private-camera
rules still apply. Secure connections retain account permissions and normal
certificate checks. A no-login local connection is unencrypted and does not use
Frigate account camera restrictions; keep it on a trusted private network.

A working smaller stream can remain in use. This feature does not reduce the
camera's resolution, convert its video format, or remove a TV decoder limit.
The affected Philips setup still needs a retest with this version, including
the separate [oversized-stream report in issue #22](https://github.com/VibeCodingAntagonist/opah-frigate-tv-app/issues/22).

Thanks to [megabitus98](https://github.com/megabitus98) for the local-connection
