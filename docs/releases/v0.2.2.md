# Opah 0.2.2

Opah 0.2.2 makes first-time setup easier and adds faster ways to handle camera
activity.

## What changed

- Setup fields now work more reliably with a television remote, keyboard, or
  mouse.
- **Test connection** keeps the server address, username, and password in place.
- Opah asks before leaving setup when unfinished changes would be lost.
- Review items can be marked as reviewed.
- Reviewed items have a clear **Reviewed** label in the Review list.
- Compatible button-mapping and home-automation apps can open a chosen live
  camera directly.

## Update

Download `opah-v0.2.2.apk` under **Assets** and open it on the TV. Android should
offer to update Opah while keeping the saved connection.

For a new installation, or if you need more help, follow the
[step-by-step installation guide](../installation.md).

Only download Opah from this GitHub repository. Do not install copies from
unofficial APK websites or mirrors.
