# Opah 0.2.1

Opah 0.2.1 is a small maintenance update. Cameras, Review, recordings, and
playback work the same as they did in 0.2.0.

## What changed

- Updated the text and artwork shown in the TV launcher and while Opah starts.
- Added an **About** page with the installed version, privacy information,
  license, official GitHub project link, and support information.

## Important: uninstall 0.2.0 first

Versions 0.2.0 and 0.2.1 use different security keys, so Android cannot install
0.2.1 over 0.2.0.

1. Uninstall Opah 0.2.0.
2. Install `opah-v0.2.1.apk`.
3. Enter the Frigate server address, username, and password again.

Uninstalling removes the saved connection from the TV. Later releases should
install as normal updates.

## Install

Under **Assets** on this release, download `opah-v0.2.1.apk`. Then follow the
[step-by-step installation guide](../installation.md).

Only download Opah from this GitHub repository. Do not install copies from
unofficial APK websites or mirrors.
